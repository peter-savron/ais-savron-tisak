# RawSpec text files

On the first sync,  create `<user-directory>/workspaces/<workspace-name>/specs/<spec-name>/` inside the [workspace directory](Workspace.md). Treat the spec name as a single stable component following the [name identifier rules](../../features/NameIdentifier.md). Reject names reserved by the host filesystem or colliding with another component under filesystem name comparison.

Use `<label>-<rawspec-uuid>.<ext>`. For the label, take the upstream basename without its final extension, lowercase ASCII letters, replace runs outside ASCII letters and digits with a hyphen, limit to 40 characters and strip boundary hyphens. Use `spec` for an empty label. The RawSpec UUID identifies the logical spec. Fix the label at first publication so edits remain at one path. Record the path per revision if the output extension changes. Use `.md` for Markdown and `.txt` for plain text. For example, a locator ending in `Install Guide.pdf` yields the label `install-guide`. Never interpolate the full upstream path into the destination.

## Per-file history

Initialize a local Git repository with Eclipse JGit in this managed output directory. The upstream source directory remains read-only. Track only managed output files. A stable path makes ordinary per-file inspection possible with `git log -p -- <filename>`. Storage compares the recorded paths and blobs at the requested revisions, including across extension changes. JGit supplies commit trees, path filtering and unified patch formatting. A custom diff store would also need its own revision lookup, patch format and inspection tooling. [JGit DiffFormatter](https://archive.eclipse.org/jgit/site/6.3.0.202209071007-r/org.eclipse.jgit/apidocs/org.eclipse.jgit/org/eclipse/jgit/diff/DiffFormatter.html)

Publish exactly one Git commit per completed source sync. Stage all successful file additions, updates, restorations and removals in that commit. An empty, metadata-only or partially successful sync still gets one commit, even when its tree equals its parent. Record the sync ID and return the commit ID as the publication revision. A retry recovering that same sync reuses its commit. A fresh invocation has a new sync ID. An aborted publication cannot advance the published head. Serialize writers per repository. Prepare and durably retain the candidate commit before the conditional [database publication](../arcadedb/Spec.md). Use the database’s committed revision as the read authority. Advance the visible branch and materialize its working tree from that revision. After interruption, reconcile the branch and working tree with the committed database pointer before the next write. Discard only unpublished candidates. Retain all published commits and their ancestors for rollback.

For a single RawSpec, physically delete its working file. Stage the path removal in the sync commit. The previous blob stays reachable. Rollback copies the retained file into a new forward commit and restores its matching metadata. Neither operation resets the repository or changes a sibling file.

Keep a durable Git ref reaching each required commit. A database object ID alone cannot protect an unreachable blob from pruning. Removing the working copy saves its space; packfiles can also compress and delta-encode similar revisions. Savings depend on the data. Anyone with repository read access can extract retained text, so enforce workspace filesystem permissions as well as application visibility. [Git maintenance](https://git-scm.com/docs/git-gc) and [Git packfiles](https://git-scm.com/book/en/v2/Git-Internals-Packfiles).

JGit may classify large text as binary at its diff size threshold. If a line diff exceeds the supported size or memory budget, return an explicit diff-unavailable result with the two revision IDs; preserve both versions for recovery. A missing or damaged repository requires backup recovery. Back up the repository refs and objects together with matching database metadata. [JGit DiffFormatter](https://archive.eclipse.org/jgit/site/6.3.0.202209071007-r/org.eclipse.jgit/apidocs/org.eclipse.jgit/org/eclipse/jgit/diff/DiffFormatter.html)
